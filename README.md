# EatQuestbot

Подбор заведений (ресторанов/кофеен) по пожеланиям пользователя.

## Учитываемые пожелания

1. Тип заведения (ресторан/кофейня)
2. Бюджет (высокий/средний/низкий)
3. Станция метро
4. Для ресторанов: вид кухни

## Бот предлагает

* 5 заведений, подходящих под критерии (их адрес, контакты и сайт, вид кухни, рейтинг)
* Возможность добавить заведение в избранное и посмотреть позднее
* Добавить в базу данных новое заведение, чтобы больше людей могли его посетить

## Необходимые для запуска библиотеки

| Библиотека | Назначение |
| :--- | :--- |
| `aiogram` | Асинхронный фреймворк для разработки Telegram-ботов |
| `supabase` | Клиент для интеграции с облачной базой данных Supabase |
| `python-dotenv` | Безопасная загрузка токенов и ключей из файла `.env` |
| `asyncio` | Инструмент для работы с асинхронным кодом в Python |
